# 重賞3連複予想帳

JRAの**週末の重賞（G1・G2・G3）だけ**を対象に、**3連複を1レース合計1,000円**で買う予想を、自動で作って公開するサイトです。
本命・中穴・大穴の点数配分は画面でいつでも変えられます。費用は0円（GitHubの無料の仕組みだけで動きます）。

サイト：https://utauka.github.io/keiba-yoso/

## いつ、何をするか（日本時間）

| いつ | 何をするか |
|---|---|
| 金・土・日 20:00 | 翌日の重賞をさがし、出馬表・各馬の過去成績・前売りオッズを取りこんで予想を作る |
| 土・日・月 9:00〜17:50 の10分ごと | 単勝・3連複のオッズを取り直して予想を更新。発走100分前からは馬体重が出るまで出馬表も取り直す |
| 発走時刻を過ぎたら | その時点の買い目で確定。10分後から結果を取りに行き、答え合わせ |

月曜は祝日開催のときだけ動きます（開催がなければすぐ終わります）。GitHubの混雑で数分〜十数分遅れることがあります。

## 買い方

- 3連複のオッズで **本命（30倍未満）・中穴（30〜99倍）・大穴（100倍以上）** に分ける
- 初期の配分は **本命4・中穴3・大穴3 の10点×100円**。画面の「本命寄り／バランス／穴寄り／大穴狙い」か ＋− で変更（スマホに記憶）
- 点数を減らすと1点あたりの金額が増えます（合計はいつも1,000円）
- 本命は当たりやすい順、中穴は当たりやすさと儲けのバランス、大穴は期待値の高い順に選びます

## 予想のしくみ（かんたんに）

1. **単勝オッズ**（みんなの評価）を土台にする
2. **能力指数**：直近5走の着順・勝ち馬との差・レースの格・同じ芝/ダートで近い距離の成績・同じ競馬場の成績・重賞での好走回数
3. **パドック指標**：馬体重の増減（±10kg以上は減点、好走時の体重に近ければ加点）と、パドックの時間帯（発走75分前〜）の単勝オッズの動き（急に売れたら加点）
4. 1に2・3を少し足して各馬の勝つ確率を出し、そこから3連複の全組み合わせの確率を計算
5. 実際の3連複オッズと比べて買い目を選ぶ

数字の調整は `config.json` で変えられます（保存すると次の更新から反映）。

## ファイル

| 場所 | 中身 |
|---|---|
| `scripts/update.py` | 1回分の更新（取りこみ→予想→答え合わせ→ページ作り） |
| `scripts/netkeiba.py` | netkeiba からの取得と読み取り |
| `scripts/model.py` | 能力指数・パドック指標・確率・買い目 |
| `scripts/build_site.py` | 画面のひな形にデータを入れて `site/index.html` を作る |
| `site/template.html` | 画面のひな形 |
| `data/races/` | レースごとの記録（予想・買い目・結果） |
| `.github/workflows/update.yml` | 自動更新の時間割 |
| `.github/workflows/probe.yml` | 読み取りがうまくいかないときの動作確認（手動） |

## 手で動かすとき

「Actions」タブ →「update」→「Run workflow」。
読み取りがおかしいときは「probe」を動かすと `data/debug/` に確認用の結果が残ります。

## 注意

- パドックの「気配・毛ヅヤ」など見た目の評価は、無料で機械的に取れるデータがないため使っていません。
- データは netkeiba のページを、少ない回数（1回ごとに1.2秒あけて）だけ読みに行っています。自分用として使い、広く公開しないでください。サイトは検索エンジンに出ない設定です。
- 予想は確率の目安で、儲けを約束するものではありません。
